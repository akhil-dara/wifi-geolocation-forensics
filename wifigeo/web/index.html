Locate a wireless network

Resolves an SSID or BSSID to a geographic position using two independent, credential-free positioning databases, cross-validates them against each other, and seals everything it touches into a verifiable evidence package.

  • Apple Location Services — per-access-point positions plus up to 400 neighbouring access points
  • Microsoft inference service — an independent position from the observed beacon fingerprint, with IP-fallback answers detected and discarded
  • OpenStreetMap — address, nearby places, elevation, timezone and map imagery embedded for offline viewing
